# MeewVision — website (proposta de redesign)

Site estático em HTML, CSS e JavaScript, sem dependências.

## Ver o site

- Abrir `index.html` no browser, ou
- Numa pasta com Node instalado: `npx serve .` e abrir o endereço que aparece.

## Continuar no Claude Code

```bash
cd meewvision-site
claude
```

O Claude Code lê automaticamente o `CLAUDE.md`, que tem a marca, as cores, a estrutura da página, as regras de conteúdo e a lista de pendentes.

## Estrutura

```
index.html          página
css/styles.css      estilos
js/main.js          interatividade (3D, galeria, filtros, formulário)
assets/img/         fotografias e logótipo do cliente
assets/video/       vídeo do hero (por colocar)
CLAUDE.md           contexto do projeto para o Claude Code
```
